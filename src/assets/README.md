# VLR Holdings Assets

## Logo Files
Place the VLR Holdings logo files in the `images/` subdirectory:
- `vlr-logo.png` - Main logo (high resolution)
- `vlr-logo.svg` - Vector logo (preferred for web)

## Favicon Files
The following favicon sizes should be generated from the VLR logo and placed in the root `public/` directory:

- `favicon.ico` - 16x16, 32x32, 48x48 (multi-size .ico file)
- `favicon-16x16.png` - 16x16 pixels
- `favicon-32x32.png` - 32x32 pixels
- `apple-touch-icon.png` - 180x180 pixels (for Apple devices)
- `android-chrome-192x192.png` - 192x192 pixels
- `android-chrome-512x512.png` - 512x512 pixels

## Generating Favicons
You can use online tools like:
- https://realfavicongenerator.net/
- https://favicon.io/

Upload the VLR logo image provided and download all required sizes.
